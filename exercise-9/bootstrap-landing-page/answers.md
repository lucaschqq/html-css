# Bootstrap landing page: my answers

## 1. Which Bootstrap classes did you use for the navbar?
      There are a few classes I used for the navbar such as "navbar navbar-expand-lg bg-body-tertiary", navbar-toggler" type="button" data-bs-toggle="collapse" data-bs-target="#navbarNav" aria-controls="navbarNav" aria-expanded="false" aria-label="Toggle navigation", "navbar-toggler-icon" and collapse navbar-collapse.

## 2. Which value on the navbar button points to the menu?
      The mainMenu in data-bs-target and mainMenu in id which is in line 22.

## 3. Which grid classes changed the layout of the hero section?
     The container gives the stucture for the section, "row, align-items-center g-4" makes it centered and makes it into a horizontal flex row while the g-4 gices it space in between.

## 4. Which card classes did you use?
    For my image i used class="card" style="width: 18rem;" and for my requirement cards i used class="requirement-card h-100 topic-card".


## 5. Which styles did you put in `custom.css`, and not as Bootstrap utility classes in the HTML?
     I changed the btn btn-primary to a custom color and a custom border for .info-panel and service panel as well as custom font-size and font-weight for .prices and .register.
