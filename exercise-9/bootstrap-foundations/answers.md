# Bootstrap foundations: my answers

## 1. What does Bootstrap do when your HTML uses `class="btn btn-primary"`?
     The 'class="btn btn-primary"' combines two bootstrap style to the classes individually,btn gets the button its shape and structure such as the padding and the rounded corners.The btn-primary gives it a blue background from the bootstrap style with white font.

## 2. Why does this lesson load Bootstrap before `custom.css`?
       This lesson loads Bootstrap before custom.css so that custom.css can overwrite the bootstrap css so that you can still make changes to it.

## 3. What are the three main layers in the nesting pattern of the Bootstrap grid?
      The three main layers in the nesting pattern of the Bootstrap grid is container,row then column
