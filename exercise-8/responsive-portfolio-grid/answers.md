# Responsive portfolio grid: my answers

## 1. Which element became the grid container?
     .resourced-grid becomes the grid container.

## 2. Which elements became the grid items?
     .resource-card becomes the grid items.

## 3. Which rule makes the columns for wide screens?
      .grid-column makes the columns for wide screens.
 
## 4. Which rule changes the layout for a browser window of medium width?
      The rule @media (max-wdith: 820px) changes the layout for a browser window of medium width.

## 5. Which rule stops the featured card from making the phone layout too wide?
     The @media (max-width: 560px) rule and setting .grid-column: auto; on .project-card.featured stops the featured card from making the phone layout too wide.
