# Responsive card gallery: my answers

## 1. Which element became the flex container?
      The element <section> became the flex container

## 2. Which elements became the flex items?
     .card-gallery and .gallery-card became the flex items

## 3. Which CSS property controlled the space between the cards?
     gap is the CSS property that controls the space between the cards

## 4. Which CSS property let the cards move onto a new row?
      flex-wrap:wrap; lets the cards moves onto a new row

## 5. What happened when you changed the starting width of the cards?
     If i change the starting width of the cards the amount of cards on each row will be more or less depending on the width that is set
