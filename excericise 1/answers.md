# HTML page structure: my answers

## 1. What is the job of the `head`?
     the head is the start of the information we code for the browser


## 2. What is the job of the `body`?
     the body is what allows us for what we code to be shown on the website


## 3. Why does `<title>` change the browser tab, and not the visible page?
     '<title>' changes the browser tab title


## 4. When must you use `<ol>`, and not `<ul>`?
     '<ol>' is ordered list and when the order of something is important and '<ul>' is unordered list when the order of something isnt important

## 5. Why must an image have useful alt text?
      so that when the image doesnt load we can know what is supposed to be shown


## 6. What connects a `<label>` to an `<input>`?
    a label and input is connected when the value inside is the same
