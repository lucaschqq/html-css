# Image positioning: my answers

## 1. When must an image go in the HTML, with `<img>`?
      An image must go in the HTML with <img> because the image file is in the images folder.

## 2. When must an image go in the CSS, with `background-image`?
      An image must go in the CSS with background-image when it is used for decorative purposes.

## 3. What does `object-fit: cover` do?
      Object-fit cover fills the space while keeping the images original size without streching it.

## 4. Why does `.photo-panel` need `position: relative`?
     .photo-panel needs position:relative so that it can pin itself inside the images frame.

## 5. What makes the text easy to read on top of the background image?
      Making the text have a higher font-weigth and size while also giving it a darker color if the background image is lighter.
